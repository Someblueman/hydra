# Optional native core

Hydra remains a POSIX shell CLI. The native core introduced in 1.7 is an optional,
read-only helper for capability reporting, state/event validation, canonical JSON
strings, and snapshot aggregation. Shell remains the sole mutation, policy, Git, hook, and
teardown authority. The accepted wire contract is [ADR 0002](adr/0002-native-protocol-v1.md).

## Build, test, and dispatch

```sh
make build-core
make test-c
make test-parity
make sanitize
make bench-core
hydra snapshot                 # canonical shell path
hydra snapshot --native        # explicit native attempt
```

Native dispatch checks protocol v1, exact Hydra/core version agreement, and applies a
bounded timeout. Missing artifacts, old protocols, release-version skew, crashes,
timeouts, malformed output, and execution permission failures emit a named diagnostic and return the shell snapshot. `HYDRA_CORE` selects
an explicit helper for qualification; `HYDRA_CORE_TIMEOUT_SECONDS` controls the
bounded check.

The 2026-08-30 macOS arm64 benchmark (`scripts/bench-core.sh`) used the same 20-head
state for three shell and three native runs. Shell measured 5459 ms cold, 5277 ms
p50, and 5459 ms p95; explicit native dispatch measured 84 ms cold, 73 ms p50, and
84 ms p95. Subprocess count and one-shot RSS were not instrumented and are reported
as such by the script. This is evidence for snapshot aggregation only; it is not a
general CLI performance claim.

## Source and offline installation

Shell-only installation is unchanged:

```sh
HYDRA_INSTALL_CORE=never HYDRA_INSTALL_TUI=never \
  PREFIX=$HOME/.local ./install.sh
```

An explicit source build installs the helper under
`$PREFIX/libexec/hydra/hydra-core`:

```sh
HYDRA_INSTALL_CORE=required HYDRA_BUILD_CORE=1 \
  PREFIX=$HOME/.local ./install.sh
```

Release artifacts are offline directories containing `hydra-core` plus adjacent
`.sha256`, `.platform`, `.dependencies`, and `.source` files. Packaging refuses a
dirty tree by default so the source identity names the exact qualified commit. Create one with
`make package-core`, then install it without network access:

```sh
HYDRA_INSTALL_CORE=required \
HYDRA_CORE_ARTIFACT=/path/to/package/hydra-core \
PREFIX=$HOME/.local ./install.sh
```

Installation verifies SHA-256, exact `uname -s`/`uname -m`, protocol version, and
Hydra/core version agreement before atomically replacing the helper. A prior helper
is retained with a `.rollback` suffix, and any replacement failure restores it.
`uninstall.sh` removes the helper, metadata, and rollback files with the shell
installation.

Supported native CI builds and qualifies current macOS and Linux hosted runners.
The metadata dependency listing is generated by `otool -L` on macOS or `ldd` on
Linux. No public `libhydra` ABI is promised in 1.8.
